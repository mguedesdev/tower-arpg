# Decisões de escopo (MVP)
- O diferencial testado agora é a modificação da geometria de ataque.
- Ataque é automático; jogador decide posicionamento.
- Construção provisória com formas geométricas simples para não bloquear desenvolvimento pelo rig.
- Não usar itens 3D equipáveis nesta fase: itens futuros terão ícones/atributos.
- Sem backend, rede, ranking ou monetização enquanto o núcleo de combate não tiver sido validado.
- Sistema de skills modular e árvores de passivas ficam para depois do primeiro teste divertido.
- Protótipo não é otimizado para centenas de inimigos: medir antes de escolher MultiMesh/pooling/grade espacial.
